# What's in the game: systems tree

Draft for markup. Coarse to fine: JEV says yes/no to each level-1 system ("use any above 60%"),
then yes/no to each level-2 part of the systems it kept. Level 3 is the concrete content
(skeletons, bats, ogres) and is not drafted yet.

This tree is what the game contains, not how the player interacts with it. Input, controls and
feel are a later step.

## Level 1: systems

| System | Level 2: parts |
|---|---|
| Combat | enemies, weapons, player health, abilities / special moves, bosses, damage types, armour / defence, allies |
| Exploration | map / world, secrets, collectibles, keys and locked doors, fast travel, landmarks |
| Puzzles | puzzle types, hints, switches and doors, physics objects, timed puzzles |
| Economy | currency, shops, prices, trading, selling |
| Inventory and items | consumables, equipment, key items, inventory limit |
| Crafting | materials, recipes, crafting stations, upgrades to crafted items |
| Resource gathering | resource types, gathering spots, respawn, tools needed |
| Farming | crops, seasons, livestock, watering / tending, harvest |
| Building | buildable pieces, placement, rooms / structures, decoration |
| Management / simulation | workers or citizens, production chains, needs, buildings with jobs |
| Survival | hunger, thirst, temperature, day / night, shelter |
| Progression | experience and levels, skill tree, unlocks, upgrades between runs, stats |
| Characters and NPCs | townsfolk, merchants, quest givers, companions, rivals |
| Story | plot, cutscenes, lore, endings |
| Dialogue | conversations, choices, relationships / affection |
| Quests | main quests, side quests, objectives, rewards |
| Creatures | collectible creatures, pets, taming, evolution |
| Stealth | guards, detection, hiding spots, noise |
| Vehicles and racing | vehicles, tracks, laps, opponents, boosts |
| Sports | ball / scoring object, teams, field, rules, matches |
| Cards and decks | cards, deck building, hand, draw / discard |
| Hazards | traps, environmental damage, falling, timers |
| Score and records | score, combos, high scores, leaderboard, medals / ranks |
| Waves and spawning | waves, spawn points, difficulty ramp |

## Open

- Missing systems? The list has to hold the right answer, as the art-style probe showed.
- Some rows lean towards "how it plays": Hazards, Waves, Score. Keep them or move them?
- Combat parts vs Waves and spawning: should waves be a part of Combat instead?
- Question wording for each level: "Does this game contain {system}?"
- Where the tree stops and the LLM takes over: level 3 everywhere, or earlier for some systems?
